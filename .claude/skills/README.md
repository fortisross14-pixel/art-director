# Game skills for this repo

Claude Code loads these automatically when working in this repository.

| Skill | Use it for | Source | License |
|---|---|---|---|
| `game-feel` | Feedback on actions: easing, pops, tiers of importance | [awesome-gamedev-agent-skills](https://github.com/gamedev-skills/awesome-gamedev-agent-skills) @ 19d93f9, unchanged | Apache-2.0 |
| `game-ui-ux` | Layout, safe areas, focus, screen stack, accessibility floors | same, unchanged | Apache-2.0 |
| `card-game` | Gala and dealer decks: zones, draws, reshuffles, fair shuffles | same, unchanged | Apache-2.0 |
| `save-systems` | Versioned saves, migration, backups | same, unchanged | Apache-2.0 |
| `balance-check` | Economy, progression, loot and minigame balance, measured with the sim | [Claude Code Game Studios](https://github.com/Donchitos/Claude-Code-Game-Studios) @ 05ad7c8, adapted to this repo | MIT |
| `ux-review` | Reviewing the real screens at phone width | same, adapted to this repo | MIT |

The four unchanged skills are written for Godot and Unity; their principles are
engine-neutral and apply to this React game as-is. License texts are in `_licenses/`.

The project's own design skill for visual work is `frontend-design` (built in).
