# Museum Wars — Restoration Build

This build restores the original simulation scope and adds the first Kairosoft-inspired visual museum layer.

## Restored simulation systems
- One inherited rare artwork at game start
- Cousin rivals who inherit the rejected family works
- Local and global museum rankings
- District/city map and multiple museum locations
- Auctions and auction-house access
- Explorers, expeditions and dig-board resolution
- Society galas and temporary artwork loans
- Black-market offers with forgery, alteration and stolen-art risks
- Staff, sponsorships, research, advertising and museum finances
- Full existing artwork catalogue and codex

## New presentation
- Chunkier game-like HUD and panels
- Clickable museum floor shown as the primary gallery view
- Visible galleries, frames, benches, visitors, entrance and closed expansion spaces
- Starting artwork pool changed to rare, non-masterpiece works so progression begins with one meaningful piece rather than famous icons

## Next visual milestone
The current floor translates the existing room state into a visual dollhouse. The next milestone is a true tile construction editor with movable walls, doors, furniture, visitor paths and service rooms.
